# rareteam Control

`rareteam Control` — центральная система ролей, модерации и доступа для всех игровых серверов проекта.

## Доступ

- Панель: `/control/` на rareteam API.
- По умолчанию панель отвечает только клиентам из loopback и частных сетей.
- Публичный доступ можно включить только явно через `CONTROL_ALLOW_PUBLIC=true`.
- Авторизация использует существующий rareteam-аккаунт.
- Первоначальный владелец — пользователь `jetarare`. Системную роль владельца нельзя удалить.

## Роли

Роли создаются динамически и поддерживают:

- название, цвет, PNG-значок и позицию в иерархии;
- произвольный набор возможностей;
- глобальную или серверную область действия;
- временную выдачу;
- несколько ролей у пользователя;
- отображение самой высокой роли в лаунчере и Minecraft TAB.

Пользователь не может создавать, изменять или выдавать роли выше собственной, а также выдавать возможности, которых у него нет.

## Модерация

- глобальные и серверные блокировки;
- временные и постоянные блокировки;
- причина и ссылка на доказательство;
- отзыв активных refresh-сессий при блокировке;
- запрет создания игрового билета;
- повторная проверка подключённых игроков каждые 10 секунд;
- автоматическое отключение уже находящегося на сервере заблокированного игрока.

## Minecraft

`rare-auth` 0.2.0:

- получает роли вместе с одноразовым игровым билетом;
- обновляет роли и баны без перезапуска;
- форматирует имя игрока;
- заменяет стандартный TAB на интерфейс rareteam;
- показывает роль, загруженный PNG-значок и пинг;
- сортирует игроков по иерархии ролей.

## Аудит

Создание, изменение, удаление и выдача ролей, а также блокировки записываются в `audit_log`.
